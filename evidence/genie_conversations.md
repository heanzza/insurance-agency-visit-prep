## Q. 解約の理由で一番多いものは？

- status: `COMPLETED` / 16.9 秒

> 解約理由ごとに解約件数を集計し、最も件数が多い解約理由を件数順に表示しています。

> 解約理由で一番多いのは **保険料負担** で、**791件**です。今回の結果では、最も多い解約理由が1件に絞られており、解約理由の中では **保険料負担** が突出しています。

```sql
WITH reason_counts AS (
  SELECT
    `reason`,
    COUNT(*) AS `lapse_count`
  FROM `jp_fsi_catalog`.`agency_visit_prep`.`silver_lapses`
  WHERE `reason` IS NOT NULL
  GROUP BY `reason`
), ranked_reasons AS (
  SELECT
    `reason`,
    `lapse_count`,
    RANK() OVER (ORDER BY `lapse_count` DESC) AS `reason_rank`
  FROM reason_counts
)
SELECT
  `reason` AS `解約理由`,
  `lapse_count` AS `件数`
FROM ranked_reasons
WHERE `reason_rank` = 1
ORDER BY `件数` DESC, `解約理由`
```

SELECT

  SUM(`k`.`pwaiver_attached_policies`) AS `attached_policies`,

INNER JOIN `jp_fsi_catalog`.`agency_visit_prep`.`gold_visit_priority` AS `p`
  ON `k`.`agency_id` = `p`.`agency_id`
WHERE `k`.`fiscal_year` = 2026
  AND `p`.`agency_name` IS NOT NULL
GROUP BY `p`.`agency_name`
HAVING SUM(`k`.`pwaiver_eligible_policies`) >= 20
ORDER BY `pwaiver_rate_pct` ASC
LIMIT 10
